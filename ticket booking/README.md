# Ticket Booking App

A full ticket booking app built with React Native (Expo) and Node.js + MySQL.

## Features
- User login/register
- View all events with search & category filter
- Book tickets (Standard or VIP)
- Select quantity
- View my bookings
- Cancel bookings
- Admin panel to add/delete events

## Setup

### Backend
1. `npm install`
2. Create MySQL database: `CREATE DATABASE ticketbooking_db;`
3. `node server.js` → runs on port 3004

### Mobile App
1. `cd mobile && npm install`
2. `npx expo start`
3. Scan QR with Expo Go
