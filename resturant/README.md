# Restaurant App

A full restaurant app built with React Native (Expo) and Node.js + MySQL.

## Features
- User login/register
- View menu with category filter
- Add to cart & place orders
- Order history with status
- Table booking
- Admin panel to add/delete menu items

## Setup

### Backend
1. `npm install`
2. Create MySQL database: `CREATE DATABASE restaurant_db;`
3. `node server.js` → runs on port 3003

### Mobile App
1. `cd mobile && npm install`
2. `npx expo start`
3. Scan QR with Expo Go
